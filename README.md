# Digital Wishbox — recreated from the reference video

A responsive React + Vite implementation of the romantic "Digital Wishbox" experience.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Customize

Edit `src/main.jsx`:
- `reasons` — change the six reason messages.
- Hero names — change "Aditya" and "Samyuktha".
- Envelope messages — edit the two surprise letters.

Edit `src/styles.css` to change the colors, spacing, typography, and responsive behavior.

The bear illustrations are original inline SVG artwork so the project does not depend on an external image asset.
